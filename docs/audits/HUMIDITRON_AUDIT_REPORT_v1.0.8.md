## 1. Executive Summary of v1.0.8 Audit Fixes

Every issue documented in `docs/audits/humid1_bump_v1.0.8.txt` and captured in `docs/audits/exhibits/v1.0.8/` has been root-caused, resolved, and verified in **`v1.0.8`**:

| # | Issue in `humid1_bump_v1.0.8.txt` | Root Cause Identified from Logs & Exhibits | `v1.0.8` Engineering Fix & Verification |
| :--- | :--- | :--- | :--- |
| **1** | **Terminus 12–14pt looked poor & 18–40pt had horizontal white CRT scanline lines passing through every char** | 1. `v1.0.7` only converted `ter-u16n.bdf` and `ter-u16b.bdf`, forcing 12–14pt and 18–40pt to scale from the 16px bitmap instead of using Terminus's 20 hand-drawn BDF strikes.<br>2. Each pixel row was emitted as a separate horizontal rectangle contour `[y_bot, y_top]`, and `bytecode-mono` omitted `FT_LOAD_NO_HINTING` (`0x2`), causing FreeType's Auto-Hinter to separate adjacent pixel rows into white horizontal scanline gaps (seen in `U+03B4_uni03B4.txt`). | 1. Hosted all 20 Terminus `.bdf` files + `OFL.TXT` directly in `assets/font_assets/terminus_v4.49.1/` (removed `.tar.gz`).<br>2. Synthesized **24 individual Terminus `.ttf` files** (`Terminus-Normal-{12..40}.ttf`, `Terminus-Bold-{12..40}.ttf`, `Terminus-VGA-{14,16}.ttf`) using a **2D connected rectilinear polygon contour tracer** where shared internal edges cancel out 100%.<br>3. Added `exact-mono` (`FT_LOAD_NO_HINTING`) so FreeType never autohints Terminus.<br>4. **Verified**: All Terminus strikes 12–40pt render with 100% solid stems and zero horizontal scanline gaps. |
| **2** | **Host CPU Idle During Conversion ("The Need for Speed!")** | Both `build_static_ttf_assets.py` and the main generator ran single-threaded `for` loops on 1 CPU core. | Added multi-process `concurrent.futures.ProcessPoolExecutor(max_workers=os.cpu_count())` (with `-j / --jobs` CLI override) to both `build_static_ttf_assets.py` and `humid1_generate_1bpp.py`, saturating all host CPU cores across TTF synthesis, FreeType rasterization, C/BDF/CSV emission, ASCII dumping, and PNG rendering. |
| **3** | **`icon_tabler_filled` 12–40 produced blank PNGs & empty ASCII folders (`0 glyphs` in log)** | `Tabler-Filled.ttf` (`1,054` filled icons at `0xEE80..0xFA6D`) shares **0 codepoints** with `Tabler-Regular.ttf` (`5,203` outline icons at `0xEA02..`). Referencing `tabler_core` (`0xEA02..`) on a `filled` strike matched `0` glyphs. | Indexed `Tabler-Filled.ttf` into its own `icon_tabler_filled` catalog (`tabler_filled_catalog.json`), added `tabler_filled_core` and `tabler_filled_all`, and routed `icon_tabler` `style="filled"` strikes to `icon_tabler_filled`. Verified `humid1_icon_tabler_filled_12..40` emits `1,051` glyphs, `1,051` ASCII `.txt` files, and 5 paginated PNGs per size. |
| **4** | **`example-build-distro` crashed with `KeyError: 'plex_mono_bold_14'` in `render_specimen_sheet`** | `render_specimen_sheet()` indexed `strike_cache["plex_mono_bold_14"]` directly, which was absent in `example.scheme.json`. | Added `_resolve_sym()` safe fallback resolution in `render_specimen_sheet()` and `run_screen_width_audit()`. Verified `example.scheme.json` completes `--workflow all` with zero errors. |
| **5** | **Batch files broke on `echo` strings (`'humid1-os' is not recognized...`, `'Char' is not recognized...`)** | Unescaped `&` in `echo ... (H1OS & humid1-os)` and `echo ... (Icons & Char PNGs)` caused `cmd.exe` to execute text after `&` as a command. | Replaced all `echo` strings across all `.bat` files with 100% typesafe plain text (`and` instead of `&`, no parentheses or pipes in `echo`). |
| **6** | **Full-Catalog Icon Proof PNGs & Removing `full-audit-build-dev`** | Auditing all icons (`2,349` FA7.3.1, `2,043` Lucide, `1,513` Phosphor, `5,203` Tabler Outline, `1,054` Tabler Filled) in a single vertical PNG would exceed 30,000px height; `full-audit-build-dev` duplicated `full-audit-build-distro`. | 1. Removed `scripts/full-audit-build-dev/`.<br>2. Configured `full_audit_distro.scheme.json` with `scope: "all"` for all icon suites and added automatic **256-glyph pagination** (`<symbol>_p01_of_05_U+EE80-U+F788.png`) in `render_full_font_inspection_png()`. |
| **7** | **Consistent `humid1_` Naming Scheme & Single Root Patch File (`font_icon_epd_patches.json`)** | `plex_icon_*`, `plex_fw_emit.py`, `plex_epd_vault.json.gz`, and duplicate patch JSONs (`epd_font_patches.json` + `plex_epd_patches.json`) were inconsistent because the toolchain handles IBM Plex, Terminus, and 4 icon suites. | 1. Renamed scripts to `humid1_generate_1bpp.py` and `humid1_fw_emit.py`, vault to `humid1_epd_vault.json.gz`, and header to `humid1_fonts.h`.<br>2. Consolidated patches into one root **`font_icon_epd_patches.json`**.<br>3. Standardized all symbols: `humid1_font_plex_<fam>_<style>_<sz>`, `humid1_font_terminus_<style>_<sz>`, and `humid1_icon_<vendor>_<style>_<sz>`. |
